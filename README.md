# 🛒 Projeto de Testes de Software - E-commerce

## 📌 Sobre o projeto

Este projeto foi desenvolvido para demonstrar conhecimentos em
Quality Assurance (QA) por meio da elaboração e execução de testes
em uma aplicação de e-commerce.

O objetivo é identificar possíveis problemas, validar funcionalidades
e documentar os resultados dos testes.

## 🎯 Objetivo

Validar as principais funcionalidades de uma aplicação de comércio
eletrônico, garantindo que os comportamentos esperados estejam de
acordo com os requisitos definidos.

## 🧪 Tipos de testes

- Testes funcionais
- Testes positivos
- Testes negativos
- Testes exploratórios
- Testes de regressão
- Testes de interface

## 🔍 Funcionalidades testadas

- Cadastro de usuário
- Login
- Logout
- Busca de produtos
- Visualização de produtos
- Adição de produtos ao carrinho
- Alteração da quantidade de produtos
- Remoção de produtos do carrinho
- Processo de checkout

## 📋 Documentação

Este projeto contará com:

- Plano de testes
- Cenários de teste
- Casos de teste
- Relatórios de bugs
- Evidências dos testes
- Resultados dos testes
