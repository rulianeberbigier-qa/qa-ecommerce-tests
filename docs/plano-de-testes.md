# Plano de Testes — E-commerce

## 1. Objetivo

Definir a estratégia de testes utilizada para validar as principais funcionalidades da aplicação de e-commerce, identificando possíveis falhas e verificando se o sistema apresenta o comportamento esperado.

## 2. Aplicação

**Aplicação:** SauceDemo

**URL:** https://www.saucedemo.com/

A aplicação será utilizada como ambiente de demonstração para a execução dos testes funcionais.

## 3. Escopo dos testes

As seguintes funcionalidades serão avaliadas:

- Login
- Logout
- Visualização de produtos
- Adição de produtos ao carrinho
- Alteração da quantidade de produtos
- Remoção de produtos do carrinho
- Processo de checkout

## 4. Tipos de teste

Serão utilizados os seguintes tipos de teste:

- Testes funcionais
- Testes positivos
- Testes negativos
- Testes exploratórios
- Testes de regressão
- Testes de interface

## 5. Ambiente de teste

**Sistema operacional:** Windows

**Navegador:** Google Chrome

**Ambiente:** Aplicação web

## 6. Critérios de aprovação

Um teste será considerado aprovado quando o comportamento apresentado pela aplicação estiver de acordo com o resultado esperado definido no caso de teste.

Quando o comportamento observado for diferente do esperado, o resultado deverá ser registrado e poderá gerar um relatório de bug.

## 7. Evidências

As execuções dos testes deverão ser acompanhadas de evidências, como capturas de tela, quando necessário.

As evidências serão utilizadas para comprovar o comportamento observado durante a execução dos testes.

## 8. Registro de defeitos

Quando uma falha for identificada, deverá ser registrada contendo, sempre que possível:

- Título do problema
- Descrição
- Passos para reprodução
- Resultado esperado
- Resultado obtido
- Severidade
- Evidência
